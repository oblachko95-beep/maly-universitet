Панель администратора

Заполните поля формами — без редактирования кода. Затем нажмите «Опубликовать на сайте» внизу страницы — изменения появятся на сайте через 1–2 минуты.

Ключ публикации (GitHub token)

Нужен один раз: с ним кнопка «Опубликовать» сразу обновляет сайт. Токен хранится только в вашем браузере и никуда не отправляется, кроме GitHub. Как получить: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → доступ только к репозиторию сайта, разрешение Contents: Read and write.
