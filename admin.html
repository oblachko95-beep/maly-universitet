Панель администратора

Заполните поля формами — без редактирования кода. Затем нажмите «Скачать файл» внизу страницы и загрузите полученный файл на GitHub.

Как сохранить изменения на сайте: 1) заполните формы ниже → 2) нажмите «Скачать файл site-data.js» → 3) на GitHub откройте репозиторий → кнопка Add file → Upload files → перетащите скачанный файл (он заменит старый) → Commit changes. Через 1–2 минуты изменения появятся на сайте.
