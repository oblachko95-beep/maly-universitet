# Малый университет КФУ — сайт

Статический сайт для школьников и родителей: курсы, подготовка к ЕГЭ/ОГЭ, олимпиады, мероприятия. Не требует сервера и базы данных — подходит для GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `maly-universitet`).
2. Загрузите **содержимое этой папки** в репозиторий (файл `index.html` должен лежать в корне).
   Можно через веб-интерфейс: **Add file → Upload files**.
3. В репозитории откройте **Settings → Pages**, в разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)` — сохраните.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

Все страницы и стили — локальные, внешних обязательных зависимостей нет (шрифт PT Sans подгружается с Google Fonts; при его недоступности сайт работает на системных шрифтах).

## Редактирование контента администратором (без разработчика)

Расписание курсов, карточки курсов, мероприятия, олимпиады, объявления, новости и ссылка на систему записи редактируются в **одном файле**:

```
data/site-data.js
```

Откройте файл в любом текстовом редакторе (или прямо на GitHub — кнопка с карандашом), найдите нужный раздел, скопируйте закомментированный пример, уберите `//` и впишите свои данные. Подробные инструкции по каждому полю — в комментариях внутри файла.

Что где редактируется:

| Что меняем | Раздел в `site-data.js` | Где появится |
|---|---|---|
| Расписание и карточки курсов | `courses` (группы `5-7`, `8-9`, `10-11`) | страница «Курсы», таблицы по возрастам |
| Ссылка на систему записи | `enrollUrl` | кнопки «Записаться» по всему сайту |
| Афиша мероприятий | `events` | страница «Мероприятия» + превью на главной |
| Олимпиады (кратко) | `olympiads` | блок «Олимпиады» на главной |
| Объявления и новости | `news` | блок «Объявления и новости» на главной |
| Ссылки верхней панели | `topbarLinks` | тёмная панель в шапке |

Пустой список `[]` — на сайте автоматически показывается аккуратная заглушка «раздел наполняется», пустых страниц не будет.

После правки сохраните файл и сделайте commit — GitHub Pages обновит сайт автоматически.

## Структура проекта

```
index.html          — главная
universitet.html    — раздел «Малый университет»
kursy.html          — курсы для 5–11 классов (таблицы по возрастам)
ege-oge.html        — подготовка к ЕГЭ и ОГЭ
olimpiady.html      — олимпиады
meropriyatiya.html  — мероприятия
foreign.html        — для иностранных граждан
zapis.html          — запись на курс + форма заявки
politika.html       — политика обработки персональных данных
data/site-data.js   — редактируемый администратором контент
assets/css/         — стили (дизайн-система: PT Sans, #0033A0, #F5A300)
assets/js/          — логика сайта (меню, поиск, cookie-баннер, формы)
```

## Встроенные механизмы

- **ФЗ-152**: все чекбоксы согласия пустые по умолчанию; отдельное согласие законного представителя для несовершеннолетних; политика ПДн в футере и у форм.
- **Cookie-баннер** при первом визите: необходимые cookie + опциональная статистика (Яндекс.Метрика подключается только после согласия).
- **Переход во внешнюю систему записи**: предупреждение «Вы будете перенаправлены…», открытие в новой вкладке.
- **Версия для слабовидящих**, хлебные крошки, поиск по сайту, адаптивные таблицы (на 360 px — горизонтальная прокрутка).

## Подключение Яндекс.Метрики (по желанию)

Счётчик добавляется только после согласия посетителя. Вставьте код счётчика в конец `assets/js/main.js`, обернув его в проверку:

```js
if (document.documentElement.hasAttribute("data-metrics-allowed")) {
  // здесь код счётчика Яндекс.Метрики
}
```
